# AsciiCube
This is a simple program that displays a 3D cube in the terminal. It is written in C.

## How to run
To run the program: clone the repository, compile with make and run the executable:
```bash
git clone https://github.com/Lotcam/AsciiCube.git
cd AsciiCube
make all
./build/asciicube
```
You can also run the program with the `-c` flad to change the character used to draw the cube:
```bash
./build/asciicube -c '@'
```
Default character is `#`.
